# 开发日志约定

## 目的

每个工作日记录项目进展，做到"完成事项可回溯、待办事项不遗漏、风险及时暴露"。

## 命名与位置

- 位置：`devlog/` 目录。
- 文件名：`YYYY-MM-DD.md`（如 `2026-10-13.md`），一天一个文件。

## 自动记录机制

- **每次开工**：运行 `node scripts/devlog.js`，若当日文件不存在则自动按模板创建。
- **追加记录**：`node scripts/devlog.js --add "完成事项描述"`，自动在「今日完成」下追加带时间戳的一行。
- AI 协作约定：每完成一个里程碑、或每次收工前，都必须把进展写入当日日志。

## 模板结构（每个日志文件）

```markdown
# 开发日志 YYYY-MM-DD

## 今日完成
- ...

## 今日待办
- ...

## 风险与阻塞
- ...

## 明日计划
- ...
```

## 维护规则

1. 完成一件、记录一件（可复用 `--add`）。
2. 待办/风险随进度更新；阻塞项写明原因与应对。
3. 里程碑完成时在「今日完成」标注对应 M 编号（如 M2 完成）。
