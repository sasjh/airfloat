# 05 · 测试与验收标准

## 1. 测试层级

| 层级 | 覆盖 | 方式 | 时机 |
|---|---|---|---|
| 单元 | 协议模块（发现/收发/策略） | `npm run test:protocol` | M2 |
| 集成 | 主进程↔协议、主进程↔UI 事件 | 手动 + DevTools | M3/M4 |
| 真机 | iPhone↔Windows 双向 | 用户配合实测 | M5 |
| 交付 | 打包 exe 可运行 | 双击运行 | M6 |

## 2. 单元测试用例（M2，protocol.test.js）

1. 两实例互相发现（getPeers 各含对方、排除自身）。
2. 单文件发送：onReceived 收到且字节一致、fileName/mime/size 正确。
3. 多文件并发发送：全部收到、无遗漏。
4. 接收策略：
   - receiveMode='off' → prepare-upload 返回 403。
   - receiveMode='contacts' 且未信任 → 403；已信任 → 200。
   - receiveMode='everyone' → 200。
5. 重名文件：落盘自动改名，不覆盖。
6. 取消/异常：cancel 后不再写入。

## 3. 验收清单（最终交付，逐条打勾）

- [ ] 1. 同一 WiFi，iPhone（官方 LocalSend）↔ 浮窗双向传图可用。
- [ ] 2. 手机→电脑：图自动进浮窗，不弹保存框、不切窗、不翻文件夹。
- [ ] 3. 电脑→手机：图出现在 iPhone 相册。
- [ ] 4. 浮窗图片可拖到微信/QQ/文件夹，松手送达。
- [ ] 5. UI 符合：淡蓝、Win+V 尺寸、左列（开关+接收对象）+ 右侧图片口。
- [ ] 6. 仅图片、常驻托盘可随时唤出。

## 4. 边界与失败场景

| 场景 | 预期 |
|---|---|
| 组播被隔离（发现不到） | 提供手动输入对方 IP / 显示本机 IP |
| HTTPS 自签证书 | iPhone 端按指纹确认一次即可 |
| HEIC 图片 | 缩略图占位、原文件可拖出 |
| 端口 53317 被占 | 换端口并广播新端口 |
| 大图/多图 | 并发上传 + 进度显示 |
| 中途取消/设备离线 | cancel 清理半成品，UI 提示 |
| 重名文件 | 自动改名 |
| 防火墙拦截 | 首次运行引导放行 |
