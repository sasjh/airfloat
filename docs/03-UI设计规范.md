# 03 · UI 设计规范

## 1. 设计原则

简洁、直观、无冗余；主色**淡蓝**；信息层级清晰；只做必要控件。

## 2. 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#EAF3FB` | 淡蓝底 |
| 主蓝（强调/按钮/开关） | `#4A90D9` | 主色 |
| 卡片/面板 | `#FFFFFF` | 白底卡片 |
| 主文字 | `#1F2D3D` | 深灰蓝 |
| 次要文字 | `#7A8B9E` | 灰 |
| 分隔线 | `#DCE8F3` | 淡蓝灰 |
| 成功/在线 | `#3EB489` | 绿 |
| 关闭/离线 | `#9AA7B4` | 灰 |

## 3. 窗口

- 尺寸：约 **360 × 500**（Win+V 小浮窗感）。
- 无边框、圆角、可置顶、常驻系统托盘、全局快捷键唤出。

## 4. 布局（两栏）

```
┌──────────────┬──────────────────────────┐
│  设置（左）    │  图片口（右，较宽）         │
│  ─ 隔空投送 开关│  缩略图网格               │
│  ─ 可接收对象   │  （空态：提示文字）        │
│  ─ 附近设备     │  （可拖入发送）           │
└──────────────┴──────────────────────────┘
```

- **左列第 1 行**：「隔空投送」标题 + 右侧 switch 开关（开=蓝，关=灰）。
- **左列第 2 行**：「可接收对象」+ 选择器（所有人 / 仅联系人 / 接收关闭）。
- **左列第 3 行**：附近设备列表（显示 alias + 类型图标），点击选中（选中态高亮主蓝）。
- **右列「图片口」**：接收到的图片缩略图网格；空态显示提示文案"手机发来的图会出现在这里；拖图片进来可发给手机"。

## 5. 交互

| 交互 | 行为 |
|---|---|
| 开关 | 切换 enabled（`setEnabled`） |
| 接收对象 | 切换 receiveMode（`setReceiveMode`） |
| 点选设备 | 选中发送目标 |
| 拖图片文件进右栏 | `sendFiles(选中设备, 文件路径)` |
| 拖缩略图出浮窗 | `airfloat.dragOut(filePath)` 触发系统级文件拖拽 |
| 右键/按钮 | 打开接收目录（`revealCache`） |

## 6. 状态

- 空态、接收中（进度条）、发送中（进度）、无设备（提示"未发现手机，请确认同一 WiFi"）、错误（可关闭的提示条）。
