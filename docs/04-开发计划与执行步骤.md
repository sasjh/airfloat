# 04 · 开发计划与执行步骤

> 原则：**一次只做一个里程碑，完成并验收通过后再进入下一个**。每完成一个里程碑，更新 `devlog/` 当日日志与 `docs/README.md` 状态。

## 里程碑总览

| 里程碑 | 内容 | 产出/验收 | 依赖 |
|---|---|---|---|
| M0 | 项目治理 | docs/devlog/CLAUDE.md/CONTRACT.md/package.json | 无 |
| M1 | 环境与空浮窗 | `npm install electron` 成功；无边框小窗跑通 | M0 |
| M2 | 协议核心 | `src/protocol` + `npm run test:protocol` 全绿 | M1 |
| M3 | 主进程接线 | `src/main` 把协议接入 Electron，事件转发 | M2 |
| M4 | 浮窗 UI | `src/renderer` 淡蓝设置页 + 图片口 | M3 |
| M5 | 真机联调 | iPhone↔Windows 双向传图 | M4 |
| M6 | 拖出 + 打包 | 拖到微信/QQ/文件夹 + electron-builder 打 exe | M5 |

## 各里程碑执行步骤

### M0 项目治理（当前）
- 产物：`CLAUDE.md`、`docs/`（01~06）、`devlog/`、`scripts/devlog.js`、`CONTRACT.md`、`package.json`。
- 验收：上述文件齐备且内容一致。
- ✅ 状态：进行中。

### M1 环境与空浮窗
1. `npm install --save-dev electron`（走 npmmirror + ELECTRON_MIRROR）。
2. 写 `src/main/main.js` 最小版：创建无边框 360×500 窗口，加载 `src/renderer/index.html`。
3. `npm start` 跑通，能看到淡蓝空窗口。
- 验收：窗口能打开、无报错。

### M2 协议核心
1. 按 `docs/06` + `CONTRACT.md` 实现 `src/protocol/*`。
2. 写 `src/protocol/protocol.test.js` 双实例互发自测。
- 验收：`npm run test:protocol` 输出 PASS。

### M3 主进程接线
1. `src/main/main.js` 实例化 `createProtocol`。
2. `preload.js` 用 contextBridge 暴露 `window.airfloat`（契约见 `CONTRACT.md` 第 5 节）。
3. 事件转发：onPeer→devices、onReceived→received。
- 验收：DevTools 里能拿到 state/devices 事件。

### M4 浮窗 UI
1. 按 `docs/03` 实现 `src/renderer/*`（左列设置 + 右侧图片口）。
2. 对接 `window.airfloat`。
- 验收：界面符合设计规范，开关/选择器/设备列表/缩略图交互正常。

### M5 真机联调
1. iPhone 装官方 LocalSend。
2. 双向传图验证。
- 验收：满足 `docs/05` 验收清单第 1~3 条。

### M6 拖出 + 打包
1. 拖出：`webContents.startDrag`。
2. electron-builder 打包 exe。
- 验收：满足 `docs/05` 验收清单全部 6 条；exe 可双击运行。

## 检查点（每里程碑结束必须回答）

- 是否完成本里程碑所有产出？
- 验收标准是否逐条通过？
- 是否更新了 devlog 与相关 docs？
- 有无引入新的风险/待办？（有则记录到 devlog）
