# 02 · 技术方案

## 1. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 桌面框架 | **Electron** | 内置 Node 网络能力；无边框小浮窗 + 原生拖文件出去成熟；HTML/CSS 易做淡蓝设置页 |
| 协议实现 | Node 内置模块（dgram/https/http/fs/crypto） | 零额外运行时依赖 |
| 图片预览 | 原生 `<img>`（jpg/png/webp/gif）；HEIC 暂用占位图标 | 避免原生依赖；HEIC 见风险 R2 |
| 打包 | electron-builder | 产出单文件 exe |
| 环境 | Node v24 / npm 11（npmmirror 镜像） | 本机已就绪 |

## 2. 架构

```
┌────────────────────────── Electron ──────────────────────────┐
│  main/（主进程）                                               │
│   ├─ main.js        窗口/托盘/快捷键/配置持久化/拖出           │
│   ├─ preload.js     contextBridge 暴露 window.airfloat       │
│   └─ (调用) protocol/                                        │
├──────────────────────────────────────────────────────────────┤
│  protocol/（纯 Node，LocalSend v2）                          │
│   ├─ cert.js        自签证书 + 指纹(SHA-256 of DER)           │
│   ├─ discovery.js   UDP 组播 224.0.0.167:53317 发现           │
│   ├─ server.js      HTTPS 接收：register/prepare-upload/upload │
│   ├─ send.js        HTTPS 发送：prepare-upload → upload       │
│   └─ index.js       createProtocol 统一入口                    │
├──────────────────────────────────────────────────────────────┤
│  renderer/（渲染进程，UI）                                    │
│   └─ index.html / styles.css / renderer.js                    │
└──────────────────────────────────────────────────────────────┘
```

## 3. 数据流

- **发现**：组播 announce ↔ `POST /register`，维护 peer 列表（去重、排除自身、60s 超时）。
- **收（手机→电脑）**：iPhone `prepare-upload`（我们的 HTTPS 服务器）→ 按接收策略 200/403 → `upload` 二进制 → 落盘 cacheDir（重名自动改名）→ `onReceived` → 浮窗缩略图。
- **发（电脑→手机）**：选中设备 → `prepare-upload` 到对方 → 并发 `upload` → iPhone 存相册。

## 4. 配置与持久化

- 配置：`app.getPath('userData')/config.json`：`{ alias, enabled, receiveMode, whitelist:[fingerprint] }`。
- 接收目录：`app.getPath('userData')/cache/`（自动创建，用户可通过 UI 打开）。

## 5. 安全

- HTTPS 自签证书（每设备一张），指纹 = 证书 DER 的 SHA-256，用于识别与信任。
- 作为客户端时 `rejectUnauthorized:false`（信任局域网内设备；指纹用于 UI 展示与"仅联系人"白名单）。
- 接收策略：everyone（全收）/ contacts（仅白名单指纹）/ off（403）。

## 6. 关键风险与对策

| 风险 | 对策 |
|---|---|
| R1 本机 GitHub 被墙 | npm 走 npmmirror、Electron 走 ELECTRON_MIRROR；协议文档已本地化（docs/06） |
| R2 HEIC 缩略图无法原生预览 | 第一版用占位图标 + 保留原文件可拖出；后续引入解码库（sharp/heic-convert）转 JPEG |
| R3 组播被路由器隔离 | 降级：手动输入对方 IP 显示本机 IP |
| R4 端口 53317 被占/被防火墙拦 | 换端口并广播新端口；首次运行引导放行 |
