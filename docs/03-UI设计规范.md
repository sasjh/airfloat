# 03 · UI 设计规范

> 依据：Apple 设计原则（字体 / 间距 / 层级 / 布局 / 交互）。
> 落地：`src_py/ui/styles.py` 是**唯一令牌来源**（颜色 / 字体 / 间距 / 圆角），
> `src_py/ui/main_window.py` 只消费令牌，不写字面量。
> 旧 Electron 版 `src/renderer/` 已废弃，不再作为规范参照。

## 1. 设计原则

简洁、直观、无冗余；主色**淡蓝**；信息层级清晰；只做必要控件。

补充（本次审计新增）：

- **对比度优先**：任何文字都必须达到 WCAG AA（正文 4.5:1），不达标的颜色一律换掉。
- **层级靠三者协同**：字号 + 字重 + 字距共同建立层级，不靠单一字号拉大。
- **用邻近性表达从属**：同组元素紧凑（2–4px），组与组之间拉开（16px）。
- **浮动层要有深度**：无边框浮窗需要投影才能从桌面上「浮」起来。
- **状态必须可见**：控件外观要如实反映真实状态（开关的开/关、选中的对象）。

## 2. 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 背景 | `#EAF3FB` | 淡蓝底 |
| 卡片 / 面板 | `#FFFFFF` | 白底卡片 |
| 主文字 | `#1F2D3D` | 深灰蓝，白底 13.99:1 |
| 次要文字 | `#5A6B7E` | 白底 5.47:1 / 蓝底 4.87:1 |
| 分隔线 | `#D3E2F0` | 淡蓝灰发丝线 |
| 装饰浅蓝 | `#4A90D9` | **仅**作装饰填充，不作文字色 |
| 强调色 | `#2E6CB0` | 文字 4.81:1（蓝底）；其上白字 5.40:1 |
| 强调色·悬停 / 按下 | `#2A61A0` / `#24568F` | |
| 选中底 / 选中边 | `#E4EFFB` / `#BBD3EE` | 选中行浅底（其上强调色文字 4.64:1） |
| 悬停底 | `#EEF4FB` | 中性，不与选中的强调底混淆 |
| 成功 / 在线 | `#1E7D5C` | 白底 5.07:1 |
| 错误 | `#B3403C` | 其上白字 5.65:1 |
| 关闭 / 离线 | `#9AA7B4` | 开关「关」轨道 |

**约束**：新增颜色必须标注实测对比度；白字底 / 文字色一律 ≥ 4.5:1。
`PRIMARY #4A90D9` 与旧的成功色 `#3EB489` 对比度不足，已降级为装饰 / 替换。

## 3. 字体

角色化排版（`styles.TYPE`，单位 px）：

| 角色 | 字号 / 字重 / 字距 | 用途 |
|---|---|---|
| brand | 15 / 700 / −0.3 | 品牌名（大字号收紧字距） |
| rowLabel | 13 / 600 / 0 | 侧栏行标题（隔空投送） |
| groupTitle | 11 / 600 / +0.4 | 分组小标题（小字号略放字距） |
| control | 13 / 400（选中 600） | 选项 / 按钮 |
| itemTitle | 13 / 600 / 0 | 设备别名 |
| itemSub | 11 / 400 / +0.3 | 设备类型等副行 |
| caption | 11 / 400 / +0.2 | 缩略图文件名 |
| emptyTitle / emptyBody | 14 / 600、12 / 400 | 空态主 / 副文案 |
| status | 11 / 400 / +0.3 | 状态栏 |
| button | 13 / 600 / 0 | 「发送」 |

**约束**：字号不得低于 11px（原 10px 的缩略图文件名已上调）；字距随字号反向变化；
字号 / 字重只在 `type_font()` 里定义，不在 QSS 里再写一套。

## 4. 间距与圆角

- **间距**：4pt 网格（`SPACE_1..4 = 4 / 8 / 12 / 16`）。
  侧栏内边距 12/14；「标题 → 条目」4px；条目之间 2px；**分组之间 16px**。
- **圆角阶梯**：窗口 12 → 卡片 / 按钮 10 → 控件 / 列表项 8（不再出现 7/16 等随手值）。
- **顶栏 40 / 状态栏 36**；「发送」按钮 76×30，状态栏内留有呼吸空间。
- **窗口**：内容区 360×500（文档约定值不变）；四周额外 12px `GUTTER` 用于投影，
  故窗口实际尺寸 384×524。

## 5. 布局（两栏）

```
┌──────────────┬──────────────────────────┐
│  设置（左）    │  图片口（右，较宽）         │
│  ─ 隔空投送 开关│  缩略图网格               │
│  ─ 可接收对象   │  （空态：提示文字）        │
│  ─ 附近设备     │  （可拖入发送）           │
└──────────────┴──────────────────────────┘
```

- **左列第 1 行**：「隔空投送」标题 + 右侧 switch 开关（开=强调蓝，关=灰）。
- **左列第 2 行**：「可接收对象」+ 选择器（所有人 / 仅联系人 / 接收关闭）。
- **左列第 3 行**：附近设备列表（alias + 类型图标），点击选中（选中态为强调色实底 + 白字）。
- **右列「图片口」**：接收图片缩略图网格；空态提示「手机发来的图会出现在这里；拖图片进来可发给手机」。
- **顶栏**：品牌 + 本机别名 + 打开接收目录（📁）+ 关闭（✕），整条为拖动区。

## 6. 交互

| 交互 | 行为 |
|---|---|
| 开关 | 切换 enabled（`setEnabled`）；拇指滑动 ease-out ≈150ms，可打断 |
| 接收对象 | 切换 receiveMode（`setReceiveMode`）；选中行加粗 + 浅底 + 描边 |
| 点选设备 | 选中发送目标（强调色实底） |
| 拖图片文件进右栏 | `sendFiles(选中设备, 文件路径)`；拖入时显示虚线提示层 |
| 拖缩略图出浮窗 | `airfloat.dragOut(filePath)` 触发系统级文件拖拽 |
| 右键 / 按钮 | 打开接收目录（`revealCache`） |
| 关闭按钮 / Esc | 关闭窗口（无边框窗口必须给出「出口」） |

## 7. 状态

- 空态、接收中 / 发送中（进度条）、无设备（提示「未发现手机，请确认同一 WiFi」）、错误（Toast）。
- **状态栏互斥**：传输中只显示「进度 + 百分比 + 文件名」，状态提示与接收计数让位，
  避免 336px 一行挤四样；传输结束后恢复。
- **Toast**：淡入 + 轻微上浮；成功 / 错误用深色填充保证白字对比度。

## 8. 无障碍

- 次要文字 / 强调色文字 / 白字填充均 ≥ 4.5:1（见 §2）。
- 所有可点控件有可见键盘焦点环（含自绘开关）。
- 尊重系统「减少动态效果」（`SPI_GETCLIENTAREAANIMATION`）：关闭时动效直接落终态。

## 9. 待办（已知差距，尚未实现）

- 深色模式：当前为纯浅色硬编码，未跟随系统明暗。
- 「仅联系人」信任名单尚未接入（协议侧）。
- 长设备名在 158px 侧栏仍会省略号截断（已有 tooltip 兜底）。
