# AirFloat 项目文档索引

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `01-需求规格说明书.md` | 要做什么、不做什么、验收标准 | 任何阶段对齐需求 |
| `02-技术方案.md` | 技术选型、架构、数据流、安全 | 写代码前 |
| `03-UI设计规范.md` | 配色、尺寸、布局、交互 | 做界面（M4）前 |
| `04-开发计划与执行步骤.md` | 里程碑、执行顺序、检查点 | 每次开工对齐进度 |
| `05-测试与验收标准.md` | 测试层级、用例、验收清单 | 每个里程碑收尾 |
| `06-协议参考-LocalSend-v2.md` | LocalSend v2 协议完整参考 | 实现协议（M2）时 |

另有：
- 根目录 `CONTRACT.md`：团队并行协作的**接口契约**（协议模块 / UI / 主进程之间的 API 约定）。
- 根目录 `CLAUDE.md`：AI 工作入口与总指引。
- `devlog/`：每日开发日志。
