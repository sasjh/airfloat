# 03 · UI 设计规范（毛玻璃版）

> 依据：Apple 设计原则（材质 / 字体 / 间距 / 层级 / 布局 / 交互），技能 `apple-design`。
> 落地：`src_py/ui/styles.py` 是**唯一令牌来源**（材质 / 颜色 / 字体 / 间距 / 圆角），
> `src_py/ui/main_window.py` 只消费令牌，不写字面量；
> 矢量图标在 `src_py/ui/glyphs.py`，窗口级亚克力在 `src_py/ui/glass.py`，
> 液态玻璃的光影原语（`paint_glass` / `PressSpring` / `GlassSurface`）在 `src_py/ui/liquid.py`。
> 液态玻璃光影参考 `rdev/liquid-glass-react`（MIT），取舍见 §2.1。
> 旧 Electron 版 `src/renderer/` 已废弃，不再作为规范参照。

## 1. 设计原则

简洁、直观、无冗余；主色**淡蓝**；信息层级清晰；只做必要控件。

补充（毛玻璃版新增，四条主线）：

- **低透毛玻璃**：材质面要「实」到压得住背后的杂色 —— 内容（照片 / 文件名 / 正文）坐在
  **低透**（`GLASS_SURFACE = 0.72`）的浅色面上，绝不让桌面颜色从字底下透上来。
  通透感靠光影去换，不靠「更透明」：更透明只会换来一团灰。实测（深色壁纸）亚克力着色
  68% 时内容区已 = `#AAADB1`，100% 才 `#D8DDE3` —— 68% 已经够「低透」。
- **玻璃只做点缀**：只有「能摸的东西」套液态玻璃光影 —— 窗口外壳、按钮、菜单、浮层、
  悬停 / 按下反馈。**内容是内容**：照片瓦片、设备行一律安静（低透面 + 发丝线），
  不跟主操作抢戏。玻璃铺满 = 没有层级 = 糊。
- **渐变光影出声，分割线闭嘴**：顶栏受光 → 内容居中 → 状态栏下沉，一档亮、一档中、
  一档深，层次由光来讲；区域之间不画硬线。整窗那层「铺满上半屏的光泽带」已撤掉
  （那是奶膜，是糊的直接来源），光集中给顶栏一条受光带。
- **对比度按最差底校准**：文字不按白底校准，而按「材质最暗处」**逐层**压出来 ——
  亚克力着色 `BG #EAF4FF` @68% 压纯黑桌面 = `#9FA6AD`，再叠最重的结构洗（侧栏）+ 窗口
  底部内阴影 = `#92999F`。所有文字按它达标（≥ 4.5:1）。
- **层级靠三者协同**：字号 + 字重 + 字距共同建立层级，不靠单一字号拉大。
- **用邻近性表达从属**：同组元素紧凑（4–8px），组与组之间拉开（20px）。
- **状态必须可见**：控件外观要如实反映真实状态（圆钮的蓝/灰 = 开/关、菜单勾选 = 当前项）。
- **真实模糊而非仿色**：整窗走系统亚克力（桌面真实模糊），失败时逐级降级，不假装。
- **细节克制**：所有材质 / 光影强度都是 `styles.py` 里的**具名令牌**，组件里不准出现
  `lit=0.9`、`wash(0.06)` 这类字面量 —— 一个数值只有一处定义，才谈得上「统一」。

液态玻璃光影（§2.1 用）：

| 令牌 | 值 | 含义 |
|---|---|---|
| `GLASS_RIM_TOP` / `GLASS_RIM_BOTTOM` | `0.86` / `0.20` | 镜面边缘光：受光边（左上）亮、背光边（右下）暗 |
| `GLASS_GLOSS` | `0.30` | 顶部光泽带（自上而下渐隐） |
| `GLASS_SPECULAR` | `0.42` | 左上角镜面热点（光源在左上） |
| `GLASS_ABERRATION` | `0.18` | 边缘色差（冷 / 暖描边各偏 1px） |
| `GLASS_INNER_SHADOW` | `0.10` | 按下：玻璃压进去的内阴影 |

光影强度（**唯一一张表**，组件里不准写 `lit=` 字面量）：面积越大越克制，越小的控件越敢亮。

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `GLASS_LIT_REST` | `1.00` | 静息 |
| `GLASS_LIT_HOVER` | `1.12` | 悬停：光更足 = 更靠近手指 |
| `GLASS_LIT_PRESSED` | `0.90` | 按下：光收回去（配合内阴影） |
| `GLASS_LIT_WINDOW` | `0.55` | 整窗外壳（面积大，拉满会发灰） |
| `GLASS_LIT_LENS` | `0.55` | 隔空投送圆钮那枚小透镜 |
| `GLASS_LIT_MENU` | `0.80` | 深色菜单面（高光太亮会把白字对比度拉下来） |
| `GLASS_LIT_MENU_ROW` | `0.70` | 菜单行悬停片 |

强调色玻璃（「发送」按钮）的不透明度阶梯，每档都按最差底验过其上白字：
`ACCENT_GLASS_REST 0.94`（5.20:1）/ `ACCENT_GLASS_HOVER 0.96`（6.16:1）/
`ACCENT_GLASS_PRESSED 0.98`（7.39:1）。

**窗口级实现**（`glass.py`，纯 ctypes，不依赖 Qt）：整窗走
`SetWindowCompositionAttribute(ACCENT_ENABLE_ACRYLICBLURBEHIND)` 拿**真实桌面模糊**；
`mode` 反映实际降级结果 —— `acrylic`（真模糊）/ `blur`（`DwmEnableBlurBehindWindow`，弱一档）
/ `solid`（都不支持时退化为不透明浅蓝底，保证文字永远可读）。透明区用
`SetWindowRgn` 圆角裁剪 + `DWMWA_WINDOW_CORNER_PREFERENCE` 对齐。缩放期间
`suspend()/resume()` 挂起亚克力以避免拖影（见 §6）。

### 2.1 液态玻璃（Liquid Glass）

参考 `rdev/liquid-glass-react`（MIT）：它用 SVG 位移图对**窗口背后**的内容做折射。
浏览器有 backdrop-filter / SVG filter，能直接采样背后的像素；Qt 桌面端**拿不到** ——
窗口背后的桌面由 DWM 在**窗口之外**合成（亚克力模糊本身就是 DWM 画的），Qt 读不到那层像素。
所以像素级位移折射无法移植，**能保真移植的是光影结构**（`liquid.paint_glass`，一层一层叠）：

| 图层 | 画的是什么 | 对应参考实现 |
|---|---|---|
| 底色 | 上亮下暗的半透明填充 | `blurAmount` / `saturation` |
| 顶部光泽 | 顶部 55% 高度、自上而下渐隐的白 | 表面反光 |
| 镜面热点 | 左上角一朵软椭圆高光 | 光源在左上 |
| 内阴影 | 按下时顶边压暗 | 按下态 |
| 边缘色差 | 冷 / 暖描边各偏 1px | `aberrationIntensity` |
| 镜面边缘光 | 对角渐变描边（左上亮 → 右下暗） | 位移造成的边缘亮边（`displacementScale`） |

- **只画光、不铺底**：`tint=None / alpha=0` 时内部完全透明，绝不挡住背后的真实模糊；
  浅材质面 `alpha=0.72` 是「低透」而不是实底。`lit` 统一缩放高光强度（`lit=0` ⇒ 整块透明），
  取值一律走 §2 的光影强度表，组件里不写 `lit=` 字面量。
- **整窗不铺光泽带**：`AirFloatWindow.paintEvent` 用 `gloss=False` 调用 —— 铺满上半屏的那层
  白是「奶膜」，会把内容洗灰（= 糊）。整窗的光只留：对角镜面边缘光 + 左上镜面热点 +
  边缘色差 + 顶栏受光带（`TOPBAR_SHEEN`）+ 底部内阴影。
- **结构分区不套边缘光 / 色差**（`GlassSurface`）：侧栏 / 图片口是铺满的，全出血矩形上画描边
  就变成硬分割线，与「区域之间不画硬线」冲突 —— 它们只保留底色 + 顶部光泽。
- **回弹**（`PressSpring`）：按下缩 3.5%，松手用 `OutBack` 弹回（对应 `elasticity`）；
  尊重系统「减少动态效果」，关闭时直接落终态。
- **容器不再自己铺底色**：侧栏 / 图片口 / 图标按钮 / 「发送」的底色都改由 `paintEvent` 画，
  QSS 一律 `background: transparent` —— 任何底色都会把玻璃盖掉。
- **删除键的遮罩片取 0.58**：它压的是**任意照片色**，0.58 才能保证白字形在纯白照片上仍有
  4.74:1（≥ 3:1 是图标底线）；更轻的玻璃会把白字形洗掉。

### 2.2 玻璃出现在哪里（点缀清单）

「玻璃效果仅做点缀」落到代码上就是一张名单 —— 名单外的表面一律安静：

| 表面 | 材质 | 说明 |
|---|---|---|
| 窗口外壳 | 亚克力 + 边缘光 + 镜面热点 + 色差 + 顶栏受光带 | 唯一的「大面积玻璃」，且不做光泽铺底 |
| 顶栏图标按钮（文件夹 / 关闭） | 液态玻璃片 + 悬停 / 按下 / 回弹 | 能摸的东西，给足反馈 |
| 「发送」按钮 | 强调色液态玻璃（`ACCENT_GLASS_*`） | 主操作，全界面唯一的饱和玻璃 |
| 弹出菜单 / 菜单行 | 深色玻璃 + 行悬停片 | 浮层，浮在内容之上才配叫玻璃 |
| 缩略图删除键 | 深色遮罩片 → 悬停错误色 | 压在**任意照片**上，所以要够实（0.58） |
| 隔空投送圆钮 | 强调色实心 + 一层小透镜高光 | 只压一层，多一层就像贴纸 |
| 卡片 / 侧栏 / 图片口托盘 | **只留低透的底**：`GlassSurface` 不套边缘光 / 色差 | 结构分区，靠材质轻重分层次 |
| 照片瓦片（缩略图） | **不套玻璃光影**：低透面 + 发丝线 | 内容是内容，不该有光泽和色差 |
| 设备行 | 透明；悬停 `CHIP_ALPHA`、选中强调色实底 | 列表是内容 |

## 3. 配色

文字色按**最差底 `#92999F`** 校准（而非白底）。它是逐层压出来的：
`#EAF4FF` @68% 压纯黑 → `#9FA6AD`，叠侧栏深色洗 → `#969DA4`，再叠底部内阴影 → `#92999F`：

| 用途 | 色值 | 实测对比度 |
|---|---|---|
| 材质基色 | `#EAF4FF` | 淡蓝底（亚克力 68% 压纯黑 = `#9FA6AD`；叠结构与底影 = `#92999F`） |
| 浅材质面 | `#FFFFFF` | 卡片 / 按钮叠加层基色 |
| 主文字 | `#1B222C` | 最差底 5.55:1 |
| 次要文字 | `#28303A` | 最差底 4.62:1 |
| 强调色 | `#2E6CB0` | 其上白字 5.40:1 |
| 强调色·图标底 | `#1568C8` | 圆钮上白色字形 5.46:1 |
| 关闭态圆钮 | `#6B7280` | 其上白色字形 4.82:1 |
| 成功（文字） | `#08331F` | 最差底 4.84:1 |
| 成功填充 | `#1E7D5C` | Toast 底，白字 5.07:1 |
| 错误填充 | `#B3403C` | 其上白字 5.62:1（悬停 `#9C3532`） |

悬停 / 按下：`ACCENT_HOVER #2A61A0` / `ACCENT_PRESSED #24568F`。

**约束**：新增颜色必须标注实测对比度；文字色一律 ≥ 4.5:1，图标（非文字）≥ 3:1。
`PRIMARY #4A90D9` 与旧成功色 `#3EB489` 对比度不足，已降级为装饰 / 替换。
底色最差处是「纯黑桌面 + 最重的结构洗 + 底部内阴影」——浅色桌面上实际对比度更高，
此基线是最保守下界。三层的参数都取自 `styles.py` 的令牌，`test_ui.py` §13 直接按令牌
重算这个最差底，所以调透明度/洗色/底影时会立刻暴露对比度是否还达标。

## 5. 间距与圆角

- **间距**：4pt 网格（`SPACE_1..6 = 4 / 8 / 12 / 16 / 20 / 24`）。
  侧栏内边距 12；「卡片 → 分组标题」20px；「标题 → 列表」4px；列表项之间 2px。
- **圆角阶梯**（`RADIUS_*`）：窗口 **8** → 卡片 / 缩略图 **14** → 控件 / 菜单行 **10** →
  弹出菜单 **18**。不再出现 7/16/12 等随手值。
  窗口的 8 不是随手取的：模糊由 DWM 画、只认 `DWMWA_WINDOW_CORNER_PREFERENCE` 的系统圆角
  （100% DPI 下 8px，随 DPI 缩放，**应用无法指定更大值**），窗内自绘半径必须与它同心，
  否则圆角处会出现两条不同心的弧。
- **几何常量**（`main_window.py`）：
  - 窗口：`DEFAULT_WINDOW = (400, 560)`、`MIN_WINDOW = (340, 440)`；**无 GUTTER**（玻璃即窗口，不为投影留白）。
  - 侧栏宽 158；顶栏 44；状态栏 36；图标按钮 26；「发送」按钮 76×30。
  - 卡片 134×132，圆钮直径 44；缩略图 84×62 + 18px 文件名；网格间距 8；
    删除键 20px（内缩 4px）；菜单宽 196、行高 44、内边距 6、投影留边 14。

## 6. 布局（两栏）

```
┌──────────────┬──────────────────────────┐
│ 顶栏：品牌 · 本机别名       📁  ✕（拖动区）  │
├──────────────┼──────────────────────────┤
│ 设置（左）    │  图片口（右，较宽）         │
│  ─ 隔空投送卡片│  缩略图网格（每张带删除键）  │
│    （圆钮+取值）│ （空态：提示文字）         │
│  ─ 附近设备    │  （可拖入发送）           │
├──────────────┴──────────────────────────┤
│ 状态栏：将发送到 / 计数 / 进度    [发送]      │
└─────────────────────────────────────────┘
```

- **左栏第 1 行**：隔空投送**模块卡片**（对齐 iOS「隔空投送」模块）——左上角 44px 圆钮
  （开=强调蓝实心 + 白字形；关=灰圆钮），左下角两行：`隔空投送`（cardTitle）+ 当前取值
  `所有人 ⌄`（cardValue）。
- **左栏第 2 行**：「附近设备」列表（别名 + 类型图标），点击选中发送目标。
- **右栏「图片口」**：接收图片缩略图网格（列数随窗口宽度自适应）；空态提示
  「手机发来的图会出现在这里；拖图片进来可发给手机」。
- **顶栏**：品牌 + 本机别名 + 打开接收目录（矢量文件夹）+ 关闭（矢量 ✕），整条为拖动区。

## 7. 交互

| 交互 | 行为 |
|---|---|
| 点卡片圆钮 | 切换 enabled（`setEnabled`）；圆钮蓝/灰即时反映开/关 |
| 点卡片其余部分 | 打开「可接收对象」菜单（`Qt.Popup`） |
| 菜单选项 | 接收关闭 / 仅限联系人 / 所有人，**选中项前置对勾**；选「接收关闭」= 关开关但**记住**上次模式 |
| 点菜单外 / Esc | 关闭菜单（Qt.Popup 原生行为） |
| 点选设备 | 选中发送目标（强调蓝实底 + 白字） |
| 拖图片文件进右栏 | `sendFiles(选中设备, 文件路径)`；拖入时显示虚线提示层 |
| 拖缩略图出浮窗 | `airfloat.dragOut(filePath)` 触发系统级文件拖拽 |
| 缩略图右上角 ✕ | 从收发列表移除该图（悬停变红；同步清掉待发包） |
| 拖窗口边 / 角 | **八向缩放**（6px 热区；系统缩放优先，失败回退手动；最小 340×440） |
| 拖动顶栏 | **自己跟手移动**窗口（`QWindow.startSystemMove()` 在本机返回 True 却纹丝不动，已弃用；玻璃圆角随之重算） |
| 悬停图标按钮 | 浮出一片玻璃（`_GlyphButton` 的 tone）；关闭 / 删除键悬停转错误色 |
| 按下按钮 | 玻璃压进去（内阴影）+ 缩 3.5%，松手 `OutBack` 弹回 |
| 缩放窗口 / 连收多图 | 缩略图重建时旧图先摘除并隐藏，避免与新图叠在一起 |
| 右键 / 📁 | 打开接收目录（`revealCache`） |
| 关闭按钮 / Esc | 关闭窗口（无边框窗口必须给出「出口」） |

**移动 / 缩放的材质处理**：拖动窗口或拖拽缩放时 `material.suspend()`（切成纯色，避免亚克力
拖影），停手 `RESIZE_SETTLE_MS = 180ms` 后 `resume()` 切回真模糊；窗口几何用 `QSettings`
持久化；最大化时不套圆角裁剪。

## 8. 状态

- 空态、接收中 / 发送中（进度条）、无设备（提示「未发现手机，请确认同一 WiFi」）、错误（Toast）。
- **状态栏互斥**：传输中只显示「进度 + 百分比 + 文件名」，状态提示与接收计数让位；
  传输结束后恢复。
- **Toast**：淡入 + 轻微上浮；成功 / 错误用深色填充保证白字对比度（成功 `#1E7D5C`、错误 `#B3403C`）。

## 9. 无障碍

- 次要文字 / 强调色文字 / 白字填充均 ≥ 4.5:1，图标 ≥ 3:1（基线 = 最差底 `#92999F`，见 §3）。
- 所有可点控件有可见键盘焦点环（含自绘卡片 / 菜单行）。
- 尊重系统「减少动态效果」（`SPI_GETCLIENTAREAANIMATION`）：关闭时动效直接落终态。
- 系统不支持亚克力时退化为纯色底，绝不退化成「半透明但看不清」。

- 长设备名在 158px 侧栏仍会省略号截断（已有 tooltip 兜底）。
