# 01 · 需求规格说明书

## 1. 背景与目标

用户在 Windows 上想要一个「隔空投送」式的图片互传工具：与 iPhone 互传图片，体验无感、界面简洁。

经可行性调研确认：Windows 无法直连 iPhone 原生隔空投送（苹果私有 AWDL 协议，Windows 无驱动/无实现）。因此**改用 LocalSend 协议**实现局域网互传，iPhone 端使用官方免费 App LocalSend。

## 2. 用户与场景

- 用户：个人，非技术背景。
- 场景：同一 WiFi 下，iPhone ↔ Windows 互传**图片**。

## 3. 功能需求

| 编号 | 需求 | 说明 |
|---|---|---|
| F1 | 手机→电脑传图 | iPhone LocalSend 发图，Windows 浮窗**自动出现缩略图** |
| F2 | 电脑→手机传图 | 浮窗里选图/拖入图，发到 iPhone 相册 |
| F3 | 不弹保存框 | 收到的图自动落盘，不弹"另存为"对话框 |
| F4 | 拖出即送达 | 浮窗缩略图可拖到微信/QQ/文档/文件夹，松手送达 |
| F5 | 仅图片 | 只处理 jpg/png/webp/gif/heic 等图片，非图片第一版不传 |
| F6 | 小浮窗 | 尺寸类似 Win+V 剪贴板历史，常驻托盘、可随时唤出 |
| F7 | 接收开关 | 左列第 1 行「隔空投送」开关 |
| F8 | 可接收对象 | 左列第 2 行：所有人 / 仅联系人 / 接收关闭 |
| F9 | 图片口 | 右侧展示接收图片缩略图 + 拖入发送区 |

## 4. 非功能需求

- UI：**淡蓝主色**、简洁直观、iOS 设置页列表风格。
- 界面语言：中文。
- 稳定：单机可运行、不崩溃；传输失败可重试。
- 轻量：不依赖外部服务器；无需账号登录。

## 5. 明确不做（Non-goals，本版范围外）

- 不做 iPhone 系统原生「隔空投送」入口（真·AWDL，属后续路线 B）。
- 不做视频/文档等非图片文件。
- 不做「环」（用户已明确取消）。
- 不做多平台（本版仅 Windows）。
- 不做公网/跨网传输（仅局域网）。

## 6. 验收标准（最终交付必须满足）

1. 同一 WiFi，iPhone（官方 LocalSend）↔ 本浮窗双向传图可用。
2. 手机→电脑：图自动进浮窗，不弹框、不切窗、不翻文件夹。
3. 电脑→手机：图出现在 iPhone 相册。
4. 浮窗图片可拖到微信/QQ/文件夹，松手送达。
5. UI 符合：淡蓝、Win+V 尺寸、左列（开关+接收对象）+ 右侧图片口。
6. 仅图片、常驻托盘可随时唤出。
